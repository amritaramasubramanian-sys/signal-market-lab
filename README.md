# SIGNAL | Market Intelligence Lab

An independent educational prototype exploring how market expectations, uncertainty, and liquidity can influence prices.

## Run locally
Open `index.html` in any modern browser. No installation, API key, or external data source is required.

## What it demonstrates
- Interactive market-belief, uncertainty, and liquidity controls
- Simulated probability, fair-value estimate, and bid-ask spread
- Illustrative price path that responds to user assumptions
- Plain-language explanation of how liquidity changes estimated price impact

## Important limitations
This is a learning prototype, not a trading system. It uses simulated values rather than live market data, does not predict real events, and does not provide investment advice.
